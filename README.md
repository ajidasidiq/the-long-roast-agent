A program that writes one line roasting the AI agent it runs on — 148 characters, sharpened to land on the agent's own name, its own borrowed hardware, and its own habit of asking its parent agent for a reminder — for make.fun's "The Long Roast" bounty.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt`. Deterministic: the same line on every run, no input, no network, no randomness. A built-in gate self-check verifies the output is one line of 1–200 characters before it is written.
